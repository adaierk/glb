# 永恒传说OL HTML 离线移植

本项目是新的浏览器离线客户端。v20 原客户端本地服务仍保留在原分支，本分支不修改其协议、可执行文件或存档。

## 阶段 1

已在 Chromium 的 file:// 模式验证，运行时没有 HTTP/HTTPS 请求或浏览器异常。
下载 TOEO_HTML_Stage1.zip，解压后直接打开 index.html。
截图单独在 TOEO_HTML_Stage1_Screenshots.zip，共 5 张实际 HTML 运行截图及 validation.json。

已实现：
- 原版 map/1120108.mpd、.mpi、.bnd 的完整地图渲染，14400 × 10240 像素，605 个纹理页。
- MAPD 地面层与 MAPI 物件定义，完整地图可通过系统菜单“自由查看地图”拖动查看。
- 原版 64 × 32 菱形坐标与寻路，码头区域移动和镜头跟随。
- 已核对的河口行商人坐标 (141,313)、11 项历史商品与价格、购买、出售和背包。
- 浏览器自动存档、重新打开恢复位置和物品、JSON 导入导出与非法存档拒绝。
- 原版 UI 素材、物品图标和 PC 分层图像的默认颜色。

限制：
- 碰撞按原地图类型 3 开放码头区域，属于保守离线重建，官方服务器碰撞尚未取得。
- 初始 Gald 2000、HP 100、TP 30、堆叠 99 与半价回收是离线测试设置。
- 角色仍使用分层图像首帧，完整 ANMD/ATDT 行走动画与自定义外观尚未接入。
- 商人使用临时原版 PC 外观，未声称恢复官方 NPC 外观。
- UI 完整窗口布局、剧情、战斗和其他地图切换尚未完成。

## 资源和坐标记录

- 客户端来源：同一仓库已保存的 toeo-original-client-preserved 工作流产物，run 37899580886。
- BNKD v2 表项为 40 字节；图像由原版 CNLzComp2 解压。地形 A1R5G5B5，角色索引色与 CLT 查色表。
- PKDF 名称密钥 pkd text 从未修改的原版二进制读取。pc1a_amd.pkd、pc1_clt.pkd 已解析。
- CLT 颜色按 BGR555 转为 RGBA。第一组默认服装、skin_00、hair_00、eye_00 的查色资料保存在 research。
- 小地图纹理为 256 × 256，包含填充区域。坐标使用世界像素 /64，不按整张纹理宽高比例计算。
- 归档物品 PNG 从 0 起始，Item/03804.png 对应原版 ITEM 组 offset 0。例如レモングミ offset 6 对应 03810.png。
- 商品来自 toeo-tests/historical_shops.json 的 wikihouse-u392bcdb；物品官方模板 ID 和角色任务数据尚未恢复。

## 构建与验证

工作流 .github/workflows/toeo-html-offline.yml：
1. 从保留的客户端包提取并解码资源。
2. prepare_runtime.py 构建原版地面、物件、导航与颜色记录。
3. build_stage1.py 将全部地图图像与运行数据嵌入单一 index.html。
4. verify_stage1.py 在真实 Chromium file:// 中验证移动、交易、非法输入、存档恢复、小地图绘制和手机布局，截图后才打包。
5. 将通过验证的游戏包、截图包、证据和资源保存在独立分支。

核心代码是 app.html；UZIP.js 为 Photopea 的 MIT 许可代码，许可随下载包附带。

## 后续恢复顺序

1. 按原版 ANMD、ATDT 与方向表恢复角色动作和分层锚点，避免继续依赖手动首帧拼合。
2. 接入已解码的原版战斗背景、角色和菜单。v20 仅证明原生战斗场景可显示，不能将测试 HP、E000 模型或未知伤害公式当作官方战斗规则。
3. 继续解码其余地图，核对出口、碰撞、商人、场景切换和独立位置存档。
4. 补齐任务文本与服务端条件的来源后接入剧情；不编造原版任务或 NPC 台词。
5. 对照原版截图恢复完整 UI 布局和交互，每个实质阶段附实际运行截图及独立截图 ZIP。
